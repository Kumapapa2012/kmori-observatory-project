# フォーカス電動化 購入部品表 (初版 2026-11-23)

方式: FS90R の車輪をノブのグリップに押し当てる直接駆動 (focus_clip.scad)。Raspberry Pi Pico が PWM を出し、制御ホストとは USB でつなぐ。
価格は、確認できたものだけ記す。それ以外は、購入時に確認する。購入はユーザーが行う。

## あると便利

| 品名 | 用途 |
|---|---|
| 瞬間接着剤 | 車輪のピン (Ø1.1) を十字ホーンの穴 (Ø1.2) に留める |
| フェルト 厚み 1 mm | 爪の足の裏に貼る (フランジとの隙間 0.3 mm を押し当てに変える) |
| 両面テープ | フェルトの貼り付け |
| ユニバーサル基板 (小) + ピンヘッダー | コンデンサーと配線を 1 か所にまとめる |
| USB 電流計 | 起動時のピーク電流の確認 (制御ホストの USB3 ポート。Pico は USB2 機器なので規格上は 500 mA) |
| 熱収縮チューブ | 配線の絶縁 |

## 付属品の確認 (届いてから)
- FS90R に十字ホーンとホーンねじが付くか。データシートの図面では穴は Ø1.2、円の直径は Ø11.8 / Ø17 / Ø22.5。
- ホーンの厚みと、出力軸の先端からホーンの面までの距離 (`tip_z` = 14.3 mm は仮の値)。
